## 二、LoRA 设置（和现有 35B 模型完全相同）

| 项目 | 设置 |
|---|---|
| 基座 | Intern-S2-Preview（35B 混合专家，256 个路由专家、每个词激活 8 个，约 3B 激活） |
| 方法 | LoRA：rank 16，alpha 32（缩放 2），dropout 0.05 |
| 挂在哪里 | 语言模型的注意力层（全注意力 q/k/v/o、线性注意力 in_proj_qkv / in_proj_z / out_proj）+ 共享专家（gate / up / down），共 250 个线性层 |
| 可训练参数 | 19,169,280，占 **0.054%** |
| 冻结 | 256 个路由专家（打包成 3D 参数）、路由器、视觉编码器、时间序列模块、词表 |
| 代码位置 | `train_lora.py` 里的 `LORA_TARGETS["attn_shared"]` |

三步都在**同一个 LoRA 补丁上接着训**，全程只训练 0.054% 的参数（题目里的「参数高效」），不用多合并模型。

## 三、三步的逻辑

```
原版 35B
   │  ① 知识预训练：医学教材 + 临床指南（纯文字，整段算损失）
   ▼
知识补丁 ───────────▶ 「只做预训练」模型（顺带评测）
   │  ② 问答微调：中文医学问答 / 对话 + 六个多模态看图问答数据集（只算回答的损失）
   ▼
问答补丁 ───────────▶ 模型 B
   │  ③ 推理训练：带解析的医学考题（中英文，先给答案再给解析）
   ▼
推理补丁 ───────────▶ 模型 C
```

| 步骤 | 类比人的学习 | 目的 | 属于论文题目的哪部分 |
|---|---|---|---|
| ① 知识预训练 | 读教材、看指南 | 先让模型有医学基本认知 | 增量预训练（Incremental Pretraining） |
| ② 问答微调 | 跟诊、回答病人提问、看片子答题 | 学会按要求回答医学问题，包括看图答题 | 指令微调（Instruction Fine-Tuning） |
| ③ 推理训练 | 做带解析的考题 | 学会解释、分析为什么 | 指令微调（带解释的指令数据） |

为什么预训练只用纯文字：3B 上两次图文预训练（B2 IU X-Ray、B3 CheXpert Plus）都没帮上主任务，B2 只学会了报告写法；纯文字预训练（B1 PubMed）让纯文字医学题提高了 2.2 分。看图能力靠第②步的多模态数据练。

## 四、第①步：知识预训练语料（已定，2026-10-16 在 Hugging Face 上核实）

| 语料 | 内容 | 语言 | 全部规模 | 许可 | 本方案用多少 |
|---|---|---|---|---|---|
| **OpenMedText**（`ywchoi/OpenMedText`） | 29 本开源医学教材（解剖、生理、药理、细胞生物学、流行病学等）+ 12.1 万篇 MDPI 期刊文章 | 英文 | 教材全文 33.5 MB | 期刊文章 CC BY 4.0；教材按本分 CC BY / BY-SA / BY-NC / BY-NC-SA | **29 本教材全部**（约 800 万 token） |
| **MMedC**（`Henrychur/MMedC`） | 多语种医学语料；官方表格列了教材、过滤后的网页、医学网站、小数据集 | 8 种语言 | 255 亿 token；中文压缩包 4.6 GB，**实际只含网页语料（29 万篇，9.3 GB）和医学百科（7.58 万条，0.5 GB），没有教材** | CC BY-NC-SA 4.0 | **医学百科抽样**（约 800 万 token） |
| **Clinical Guidelines**（`epfl-llm/guidelines`） | 3.7 万篇临床诊疗指南（CCO、CDC、CMA、ICRC、NICE、PubMed、SPOR、WHO、WikiDoc），Meditron 训练语料的一部分 | 英文 | 878 MB | Common Crawl 使用条款 | **抽样**（约 400 万 token） |

- 合计约 2,000 万 token，切成最多 1,000 token 一段（训练截断 1,024），约 2.4 万段，1 轮。
- MMedC 的**英文教材没有包含**（官方说因为版权去掉了）；下载后发现**中文包里也没有教材文件夹**。所以英文知识来自 OpenMedText 教材和临床指南，中文知识来自 MMedC 的医学百科。
- **中文网页语料不用**：2026-10-16 抽 1,500 篇看过，一半以上是医院 SEO 推广页（例如「某某专科医院治鼾症手术费用」），关键词过滤分不开好坏。
- **百科也过滤推广条目**：推广用语（无痛人流、专科医院、咨询电话、免费名额等）每千字超过 2 次就跳过，抽样估计约 10%，多是公司简介、医生个人介绍和医院推广，正常的疾病条目基本不受影响。
- **验证集**：每个来源留约 1%（最多 100 段）。短篇整篇留出；教材这种长篇只留每本最后若干段，不会拿走一整本书。
- 三个语料都有非商用条款，本项目只做学术研究，论文里注明来源和许可证；处理后的数据不对外再分发。
- 下载：OpenMedText 很小，本机即可；MMedC 中文包 4.6 GB、指南 878 MB，尽量在服务器上直接下载，只解压教材部分（服务器硬盘约 88% 满）。
- 引用：MMedC — Qiu et al., *Towards Building Multilingual Language Model for Medicine*, arXiv 2402.13963；Guidelines — Chen et al., *MediTron-70B*, arXiv 2311.16079。
- 可选：混入 10–20% 通用文字一起训，减少遗忘（文献里最常用的做法）。

## 六、第③步：推理训练数据（2026-10-16 重新选定）

| 数据 | 全部规模 | 本方案用多少 | 内容 | 许可 |
|---|---|---|---|---|
| **CMExam**（`fzkuji/CMExam`，官方仓库 williamliujl/CMExam） | 68,119 题（训练 54,497 / 验证 6,811 / 测试 6,811） | 训练集抽 5,000 | 中国执业医师考试题，每题有答案和**解析** | Apache-2.0 |
| **MedMCQA**（`openlifescienceai/medmcqa`） | 训练 182,822 / 验证 4,183 / 测试 6,150 | 训练集中有解析的抽 5,000 | 印度医学考试选择题，带解析 | Apache-2.0 |
| **medical-o1-reasoning-SFT**（中文 `zh`、英文 `en` 子集） | 英文纯医学约 2 万条 | 各抽 1,500，只用最终回答 | GPT-4o 生成、经验证器检查的医学题解答 | Apache-2.0 |

- **格式：不开思考模式，「先给答案，再给解析」。** 例如「答案：C\n解析：……」。理由：
  1. 评测和上线都关闭思考模式，训练也保持一致；
  2. 长推理链要把长度上限提到 2,048–4,096，35B 上显存和时间都吃紧；
  3. 第 3 周原版开思考，21% 的题在 4,096 token 内想不完，答完的题也只提高 1.8 分；
  4. CMExam、MedMCQA 的解析本来就短，medical-o1 只取最终回答（它本身就包含分析过程），不取冗长的推理链。
- 以后有时间，可以加一个开思考的小对照，作为论文的讨论点。
- 备选：Medical-R1-Distill-Data（英文 2.2 万 / 中文 1.7 万，DeepSeek-R1 推理链，Apache-2.0）、MedReason（3.3 万条，医学知识图谱推理，Apache-2.0）。两者以长推理链为主，暂不用。
- 生成的推理不等于医生的真实诊疗过程。抽查时分别看三点：最终答案对不对、解析是否支持答案、有没有无依据的医学结论。

## 七、数据质量检查（三步通用）

1. **跨数据集去重**：每条记录保留 `source`（来源数据集）和原始 ID，跨数据集去重，不只在每个文件内部去重。
2. **测试集隔离**：训练数据与所有评测集逐条比对（题干归一化后完全相同或高度相似就剔除），包括 SLAKE 中英文测试题、MedQA 测试集、PubMedQA 考卷半边、CMExam 验证 / 测试集、MedMCQA 验证集。medical-o1 的题目来自医学考试题库，尤其要查和 MedQA 测试集的重叠。
3. **清洗**：去掉广告、联系方式、身份证号这类个人信息，去掉问答主题对不上、回答过短或模板化的样本（沿用第①步的推广用语过滤）。
4. **抽检**：每个来源随机抽 50 条人工看一遍，记录问题比例。
5. **许可记录**：每个来源单独记录许可、版本和用途。MMedC（CC BY-NC-SA）、部分教材（BY-NC）只用于学术研究。

  - CMExam 测试集抽 1,000 题，看中文医学知识；
  - 去掉图像只给文字再测一次，证明模型真的在看图；

| 评测（每个模型） | 约半天；A、B、C 共三个 |
| CheXbert 复核（容器里只能用 CPU） | 每个模型约 11 小时 |

- 显卡总共约 25 小时，用主机 0–3 号卡，训练前要和世龙协调暂停他的服务。
- 硬盘：一次只放得下一个合并好的模型（约 73 GB），要轮流合并、评测、删除；补丁（约 77 MB）永久保留。

## 十三、预期和风险

- 知识预训练可能和 3B 一样看不出提升。两个规模都没提升，本身就是有说服力的结论。
- 中文问答数据可能改善中文能力，但也可能冲淡英文和看图题，要看 A 和 S2-6datasets 的对比。
- 推理训练的提升预计主要在纯文字考题（MedQA、CMExam）上，看图题不一定变好；还要看「敢说不确定」和漏报有没有变差。
- 每个模型只训练一次。关键模型如果要写进论文，最好再用种子 43 训一次。
- 语料的非商用许可：仅限学术研究，论文中注明。
