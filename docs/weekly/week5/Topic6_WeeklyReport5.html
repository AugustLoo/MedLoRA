01 · 两个新模型 · Two new models

训练方法完全相同，只换数据Same training recipe, different data

两个新模型和现在部署的 S2-2datasets 用同一套 LoRA 设置（只训练 0.054% 的参数），唯一的区别是训练数据，所以结果的差别就是数据带来的差别。

Both use the same LoRA recipe as the deployed S2-2datasets (0.054% of parameters trained); only the data differs, so any difference in results comes from the data.

S2-6datasets
15,953 条

SLAKE、PubMedQA、VQA-RAD、PathVQA、MedQA、PneumoniaMNIST 六个数据集，只用训练部分。VQA-RAD 的测试图大多也出现在训练部分，问这些图的 1,059 道训练题全部去掉。2,991 步，5 小时 40 分。

Six datasets, train splits only. Most VQA-RAD test images also appear in its train split, so the 1,059 training questions on those images were dropped. 2,991 steps, 5 h 40 min.

S2-CheXpertPlus
10,000 对

只用 CheXpert Plus 胸片 → 医生报告（检查所见 + 结论），和 3,189 张测试片不是同一批病人。数据只在服务器上，内网传输后 1 万个文件逐个核对。1,875 步，3 小时 19 分。

CheXpert Plus X-ray → report pairs only (findings + impression), no patient shared with the 3,189 test films. The data stays on the server; all 10,000 files were checked after the internal transfer. 1,875 steps, 3 h 19 min.

03 · 漏报异常 · Missed abnormalities

上周的问题，两个新模型都改善了Last week's problem is much smaller in both new models

还是同样的 3,189 张成人胸片（2,733 张有异常），每张问两次：「有没有异常？」和「描述一下这张片子」。

The same 3,189 adult chest X-rays (2,733 abnormal), each asked twice: "Any abnormal findings?" and "Describe this chest X-ray".

漏报 · missed
01 / 04

描述漏报：68.5% → 14% 左右Described as normal: 68.5% → about 14%

现在部署的 S2-2datasets 把 68.5% 的病片描述成正常；S2-6datasets 13.8%、S2-CheXpertPlus 14.0%，都比原版的 29.2% 还低。

The deployed S2-2datasets describes 68.5% of abnormal films as normal; S2-6datasets 13.8% and S2-CheXpertPlus 14.0%, both below the base (29.2%).

02 / 04

不再自相矛盾No longer contradicting itself

是非题答「有异常」、描述却说正常：S2-2datasets 66.9%，两个新模型只有 10.2% 和 7.7%。

Answers "abnormal" yet describes the film as normal: 66.9% for S2-2datasets, only 10.2% and 7.7% for the new models.

03 / 04

直接问：漏报保持很低Asked directly: misses stay low

直接问「有没有异常」时，S2-6datasets 漏报 4.5%，和 S2-2datasets 一样低；S2-CheXpertPlus 8.7%，介于中间。

Asked yes/no, S2-6datasets misses 4.5%, as low as S2-2datasets; S2-CheXpertPlus sits in between at 8.7%.

04 / 04

代价：误报仍偏多The price: false alarms remain

正常片被说成有异常：S2-6datasets 39.4%，和 S2-2datasets 差不多；S2-CheXpertPlus 25.1%，最平衡。两个新模型各有所长。

Normal films called abnormal: 39.4% for S2-6datasets, close to S2-2datasets; 25.1% for S2-CheXpertPlus, the most balanced. Each new model has its strength.

标签由 CheXbert 从报告文字自动提取，不是医生看片标注；正常片只有 231 张，误报率是最不精确的数字；每个模型只训练、只生成一次。Labels come from CheXbert reading report text, not radiologists reading films; only 231 normal films, so the false-alarm rate is the least precise number; one training run and one decoding per model.
04 · 方法 · The judge

换一种判断方法，结论不变A second judge reaches the same conclusion

上周计划把「描述漏报」测得更准。这周用 CheXbert（生成标准答案的同一个工具）去读模型写的描述，再和标准答案对比。服务器容器里只能用 CPU，S2-6datasets 一个模型就判了 11.5 小时。

Last week's plan was a more precise omission measure. This week CheXbert — the tool that produced the gold labels — read the models' descriptions for comparison. The container has CPU only, so S2-6datasets alone took 11.5 hours.
